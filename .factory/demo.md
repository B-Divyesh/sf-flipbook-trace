# Demo contract

## Entry point

- Local: `http://localhost:5173/?demo=1`
- Production: `https://flipbook-trace.sociobot.in/?demo=1`
- `/demo` is also a direct, reload-safe alias.

The landing page reaches the demo in one click with **Try it with sample data**.

## Sample data

The demo opens with twelve Canvas-drawn frames of a paper bird moving across a guide line. Set a 1–5 second section and a frame rate, then use **Make tracing frames** to regenerate the matching count (for example, 5 seconds at 12 fps makes 60 frames). The source drawing is generated by product code. It ships with the app shell and needs no media request.

All frame controls and both free exports operate on these sample frames. The default view already shows the processed frames and export actions.

## Isolation and reset

Demo settings and frames stay in page memory only. The demo does not open or write the real `flipbook-trace` IndexedDB database or read the Studio license keys. It does not retain an imported file.

**Reset demo** rebuilds the twelve frames with default controls. **Start for real** leaves demo mode and opens the local video workspace. The banner remains visible for the whole demo route.

## Offline verification

Visit `/demo`, wait for the service worker, disable the network, and reload. The app shell and all twelve frames remain available. The automated claim test performs this sequence from a fresh browser context.
